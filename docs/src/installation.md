# Installation

PyProbs supports Python 3.11+ and has no dependencies.

First, [install uv](https://docs.astral.sh/uv/getting-started/installation/), and then add PyProbs to your project:

```console
$ uv add pyprobs
```

If you prefer to use `pip`, install it from [PyPI](https://pypi.org/project/pyprobs/) inside a virtual environment:

```console
$ pip install pyprobs
```

To try the latest unreleased changes, you can install it from [source](https://github.com/OmerFI/PyProbs):

```console
$ uv add git+https://github.com/OmerFI/PyProbs
```
