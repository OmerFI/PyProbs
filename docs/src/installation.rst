Installation
============

PyProbs supports Python 3.11+ and has no dependencies.

First, `install uv`_, and then add PyProbs to your project:

.. code-block:: console

    $ uv add pyprobs

If you prefer to use ``pip``, install it from PyPI_ inside a virtual environment:

.. code-block:: console

    $ pip install pyprobs

To try the latest unreleased changes, you can install it from source_:

.. code-block:: console

    $ uv add git+https://github.com/OmerFI/PyProbs

.. _install uv: https://docs.astral.sh/uv/getting-started/installation/
.. _pypi: https://pypi.org/project/pyprobs
.. _source: https://github.com/OmerFI/PyProbs
