Welcome to PyProbs's documentation!
===================================


Get ``True`` or ``False`` from a probability, whether you write it as a float, a percentage or a fraction.

PyProbs turns a probability into a decision. Ask for ``"25%"`` and roughly one call in four returns ``True``. You can
draw once, draw many times in a single call, or keep an instance around that remembers every result and counts them
for you.
